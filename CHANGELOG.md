# Changelog

## 0.11.0
- Maximized window on Windows; fallback sizing on other desktops.
- App icon in PNG and ICO.
- Optional drag-and-drop via tkinterdnd2; individual dropped photos supported in the UI.
- Before/after slider using protected output and original.
- Persistent local named presets.
- Optional CPU/system RAM/process memory telemetry via psutil; NVIDIA GPU system utilization/VRAM via nvidia-smi.
- Windowed Windows executable build script (not verified on Windows).
- CLI and MCP preserved from v0.10.
